# Module Loop — Інструкції та контекст для AI-агентів

Ця папка містить структуровану пам'ять, специфікації та правила для автономної розробки проєкту `finance-tracker` з використанням AI-агентів (Gemini, Claude, Antigravity).

## Навіщо це потрібно?
AI-агенти не мають пам'яті між окремими сесіями чату. Ця папка слугує «постійним жорстким диском» проєкту, з якого агент автоматично зчитує стандарти, правила гілок, структуру коду та чергу задач перед виконанням будь-якої дії.

## Структура папки:
- **`AGENT.md`** — Головна конституція проєкту (опис продукту, глосарій, критичні заборони, правила гілок). Читається агентом на початку кожної сесії.
- **`specs/`** — Технічні паспорти репозиторіїв:
  - `specs/overview.md` — загальна архітектура та бізнес-потоки.
  - `specs/backend/` — стандарти NestJS, Mongoose, DTO, правила бази даних.
  - `specs/frontend/` — стандарти React 19, Tailwind v4, Zustand, UI-компоненти.
- **`modules/`** — Робочий конвеєр:
  - `PROMPT.md` — покрокова інструкція на виконання однієї ітерації.
  - `progress-modules.md` — черга задач (`## Queue`) та база прийнятих рішень (`## Answers`).
  - `open/` — специфікації відкритих задач.
  - `done/` — завершені модулі з результатами та висновками.
  - `idea/` — беклог ідей на майбутнє.
  - `_templates/` — шаблони специфікацій.
- **`prototypes/`** — Візуальні HTML-прототипи екранів для попереднього узгодження інтерфейсу перед написанням коду.

## Головні правила розробки:
1. **Одна ітерація = один модуль.** Агент робить одну конкретну задачу за один раз.
2. **Ніколи не мерджити в `master`.** Усі зміни оформлюються в окремих гілках `feature/<slug>` та пушаться на GitHub для створення Pull Request. Злиття в `master` робить виключно власник проєкту.
3. **Мова інтерфейсу:** виключно українська.
4. **Green-gate:** перед завершенням модуля обов'язковий чистий білд (`npm run build`).
